# Seikode brand assets

- `assets/seikode-logo-with-text.png`: company symbol with the Seikode wordmark. The original wordmark was corrected using the built-in image editing tool.
- `assets/seikode-logo-symbol.png`: original company symbol without text.
- `assets/seikode-avatar-400.png`: centered 400 by 400 avatar for GitHub and LinkedIn, below 1 MB. Generated with the built-in image editing tool using the original symbol as the reference.

`profile/README.md` displays the Seikode wordmark and company tagline on the organization profile.

Older asset filenames are retained for compatibility with existing links. The old wordmark path also serves the corrected Seikode logo. Use the assets listed above for current company profiles.
